# Finance Tracker

Система финансового мониторинга и автоматизации, разработанная в рамках **производственной (эксплуатационной) практики** по направлению **02.03.03 — Математическое обеспечение и администрирование информационных систем**, профиль **Full-stack разработка**.

> 🎓 Автор: **Попов Алексей Владимирович**, НОЧУ ВО «Московский университет «Синергия»»  
> 📅 2025 г.

---

## 🎯 Цель проекта

Создать современную, масштабируемую платформу для:
- учёта доходов и расходов компании,
- автоматизации финансовых операций,
- снижения ручного контроля и ошибок.

Проект реализован в рамках **Кейса №3** и представляет собой основу для трансформации «островной» автоматизации в **стратегическую финансовую платформу**, способную опережать рост бизнеса.

---

## 🛠 Технологический стек

### Backend
- **FastAPI** — высокопроизводительный Python-фреймворк для построения API  
- **SQLAlchemy ORM** — работа с реляционной БД  
- **Pydantic** — строгая валидация данных  
- **JWT** — аутентификация и авторизация  
- Автоматическая генерация OpenAPI (Swagger UI / ReDoc)

### Frontend
- **React 18** — декларативный UI с хуками  
- **Vite** — сверхбыстрая сборка и dev-сервер с HMR  
- Компонентный подход, разделение логики и представления
